# Расписание — Telegram-бот

Бот присылает расписание занятий и замены, беря данные прямо из
Excel-файлов учебного заведения — без ИИ и без платных API.

## Возможности

- **Выбор группы** — курс → группа, через инлайн-кнопки (`/group`).
- **Расписание на сегодня/завтра** (`/today`, `/tomorrow`).
- **Расписание на неделю / на следующую неделю** (`/week`, `/nextweek`) —
  с учётом замен на конкретные даты.
- **Общее расписание** (`/schedule`) — без привязки к дате; для пар,
  чередующихся по неделям, показывает сразу оба варианта (Ч — числитель,
  З — знаменатель).
- **Замены** (`/zameny`) — список замен по группе.
- Расписание отправляется как таблица через `sendRichMessage`
  (Bot API 10.1) — с настоящими заголовками и `<table>`, без ссылок на
  внешние страницы. Если клиент не поддерживает rich-сообщения, бот
  автоматически откатывается на обычное сообщение с HTML-разметкой.

## Откуда данные

Учебное заведение публикует два файла (`.xlsx`) на странице расписания и
перезаливает их под новым именем при каждом обновлении. Бот:

1. Скачивает HTML страницы расписания (`COLLEGE_PAGE_URL`) и находит
   актуальные ссылки на файлы
   ([college_page_scraper.py](schedule_bot/services/college_page_scraper.py)).
2. Скачивает сами `.xlsx` с проверкой целостности и повторными попытками
   ([file_source.py](schedule_bot/services/file_source.py)).
3. В каждом файле несколько листов — актуальный всегда единственный
   *не скрытый* лист, остальные — история
   ([workbook.py](schedule_bot/parser/workbook.py)).
4. Разбирает таблицу с учётом объединённых ячеек, включая случаи, когда
   пара чередуется по числителю/знаменателю
   ([schedule_parser.py](schedule_bot/parser/schedule_parser.py),
   [zameny_parser.py](schedule_bot/parser/zameny_parser.py)).

Результат кэшируется в памяти (`CACHE_TTL_MINUTES`) и на диске.

## Установка и запуск

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .
cp .env.example .env       # заполнить BOT_TOKEN и COLLEGE_PAGE_URL
python -m schedule_bot
```

### Переменные окружения (`.env`)

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен бота от [@BotFather](https://t.me/BotFather) |
| `COLLEGE_PAGE_URL` | да* | Страница со ссылками на файлы расписания/замен |
| `SCHEDULE_SOURCE`, `ZAMENY_SOURCE` | нет | Прямая ссылка или локальный путь к `.xlsx` — переопределяет `COLLEGE_PAGE_URL` (удобно для разработки) |
| `CACHE_TTL_MINUTES` | нет | Как часто перезапрашивать файлы, по умолчанию 15 |
| `DATA_DIR` | нет | Куда сохранять кэш файлов и базу пользователей, по умолчанию `data` |

\* нужен `COLLEGE_PAGE_URL`, либо оба `SCHEDULE_SOURCE`+`ZAMENY_SOURCE`.

### Числитель/знаменатель

Точка отсчёта чётности недели задана константой
`_NUMERATOR_ANCHOR_MONDAY` в
[weekday.py](schedule_bot/utils/weekday.py) и подтверждена вручную для
2026/27 учебного года. При смене учебного года или если чётность
разъедется с реальной — проверьте и поправьте эту константу.

## Структура проекта

```
schedule_bot/
  bot.py, __main__.py      — сборка и запуск бота, меню команд
  config.py                — переменные окружения
  keyboards.py             — кнопки меню
  handlers/                — команды и кнопки (today, week, zameny, group...)
  services/
    college_page_scraper.py — поиск актуальных ссылок на файлы
    file_source.py          — скачивание файлов с проверкой и повтором
    schedule_service.py     — кэш распарсенных данных
    schedule_rich_view.py   — HTML для sendRichMessage (таблицы, заголовки)
    day_view.py             — запасной вариант вывода (обычный HTML-текст)
    rich_message.py         — вызов sendRichMessage напрямую к Bot API
  parser/                  — разбор .xlsx (расписание, замены)
  store/user_store.py      — хранилище «пользователь → группа» (JSON)
  utils/                   — дни недели, чётность, экранирование HTML
scripts/                   — вспомогательные скрипты для проверки парсера
```

## Технические детали

- **`sendRichMessage`** — новый метод Bot API (10.1, июнь 2026), которого
  нет в aiogram, поэтому вызывается напрямую через `httpx`
  ([rich_message.py](schedule_bot/services/rich_message.py)).
- Хранилище пользователей — простой JSON-файл (`data/users.json`), без
  базы данных: нагрузка не требует ничего сложнее.
