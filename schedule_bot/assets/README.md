# Картинки бота

Каждая — `<name>.svg` (исходник) + `<name>.png` (то, что реально отправляется).
Плоские цвета, без текста и прозрачности — рендерятся одинаково где угодно.
PNG собираются `python -m scripts.render_assets` и коммитятся.

| Файл | Где показывается |
|------|------------------|
| `welcome`   | `/start`, когда группа ещё не выбрана |
| `schedule`  | `/schedule` (общее расписание) — поясняет числитель/знаменатель |
| `zameny_ok` | `/zameny`, когда у группы замен нет |
| `updated`   | рассылка всем при перезапуске бота |
| `offline`   | сетевой сбой (сайт колледжа/Telegram не ответил) |

Если картинки нет (`photo()` вернул `None`) — бот молча шлёт текст.

Частые команды (`/today`, `/tomorrow`, `/week`, `/nextweek`, `/zameny` с заменами)
картинок не имеют специально — фото на каждый запрос расписания только мешает.
